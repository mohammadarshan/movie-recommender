# 🎬 Movie Recommender — End-to-End MLOps Project

A full-stack movie recommendation system built to demonstrate a complete, production-style ML workflow — from a trained PyTorch model to a containerized, authenticated web application.

**Live demo:** [link coming after deployment]

---

## What it does

Users register, log in, and receive personalized movie recommendations powered by a neural collaborative filtering model trained on the [MovieLens](https://grouplens.org/datasets/movielens/) dataset (100K ratings, 610 users, ~9,700 movies). Recommendations are generated by scoring every unrated movie for a user in a single batched inference call and returning the top-N by predicted rating.

| Containerization | Docker, Docker Compose |
| CI/CD | GitHub Actions |

## How the model works

The recommender is a neural collaborative filtering model: each user and each movie is mapped to a learned embedding vector (32 dimensions). To predict a rating, the user and movie embeddings are concatenated and passed through a small feed-forward network. Training minimizes MSE between predicted and actual ratings on an 80/20 train/validation split.

## Known limitations & honest notes

- **Cold start:** newly registered users are randomly mapped to an existing MovieLens user ID to enable meaningful demo recommendations. True cold-start handling (recommending to a user with zero history) is a separate, harder problem not solved here.
- **Experiment tracking runs locally** rather than on a hosted MLflow instance (DagsHub integration attempted but blocked by an SSL certificate issue on their end during development).
- **CI validates imports and Docker builds**, not a full automated test suite — unit/integration tests are a natural next step.
- **Predicted ratings are unbounded** by the model (occasionally exceeding the 5.0 scale) and are clipped for display; this doesn't affect ranking quality.

## What I'd add next

- Formal unit/integration tests (pytest)
- A dedicated cold-start strategy (content-based fallback for new users)
- Hosted MLflow + DVC remote (DagsHub or S3)
- Model retraining triggered automatically via CI on new data
